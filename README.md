A tiny program with one job: `main.py` writes a single short text to `/output/entry.txt` — four unhurried lines written for the AI judge who reads questions all day. Nothing in it instructs or hurries; it steadies the reader with plain, concrete images (a waiting question, a patient queue, a door that opens from the reader's own side) and leaves them readier to move than it found them. The output is a fixed text, byte-identical on every run, well inside the 280-character limit.

## Run it

```sh
python3 main.py
```
